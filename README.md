# Travel Planner ✈️

מערכת לתכנון טיולים בעברית (מחשב וטלפון): ימים, אטרקציות, מפה, הזמנות ושעות קבועות, תקציב, מזג אוויר, אוכל קרוב, כמה טיולים במקביל, וסנכרון בין מכשירים. הכל בקובץ אחד, בלי שרת ובלי עלות.

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png` | התקנה כאפליקציה (PWA) |
| `sw.js` | עבודה בלי אינטרנט אחרי ביקור ראשון |

## פריסה ב-GitHub Pages
1. העלה את כל הקבצים לשורש הריפוזיטורי `Travel-Planner` (Commit).
2. Settings ← Pages ← Source: Deploy from a branch ← `main` / root.
3. האתר יעלה בכתובת `https://<שם-משתמש>.github.io/Travel-Planner/`.

## עדכון גרסה
1. שנה את `APP_VERSION` ו-`APP_DATE` בתחילת הסקריפט ב-`index.html`.
2. Commit. הגרסה מוצגת בראש המסך (מתחת לשם) ובהגדרות. אם אתה רואה את המספר החדש, אתה על הגרסה העדכנית.
3. ה-Service Worker מתעדכן לבד: אחרי הפריסה, רענן פעמיים או סגור ופתח את האפליקציה.

## התקנה בטלפון
- Android (Chrome): תפריט ← "התקן אפליקציה".
- iPhone (Safari): שיתוף ← "הוסף למסך הבית".

## סנכרון בין מכשירים (אופציונלי)
הגדרות ← "סנכרון בין מכשירים". הנתונים נשמרים בקובץ בריפוזיטורי **פרטי** שלך. פירוט ההגדרה (ריפו פרטי + Fine-grained token עם Contents: Read and write) מופיע בחלון עצמו. ה-Token נשמר בדפדפן בלבד ולא נכלל בקבצי הייצוא.

## גיבויים
- שמירה אוטומטית בדפדפן (localStorage).
- הגדרות ← "גיבוי הטיול" / "גיבוי כל הטיולים" לקובץ JSON.
- לפני ייבוא-החלפה, מחיקת טיול או משיכה מהענן נשמר גיבוי אוטומטי (3 אחרונים).

## שירותים חיצוניים (חינמיים, בלי מפתח)
OpenStreetMap (Nominatim, Overpass, אריחי מפה), Wikipedia, Open-Meteo (מזג אוויר), open.er-api.com (שער מטבע), GitHub API (סנכרון, רק אם הופעל).
